
** EliteSpaceRunner

EliteSpaceRunner is the project of our team "Ctrl+Alt+Elte"

EliteSpaceRunner is a thrilling 2D space shooter game built with the Godot Engine. 
Let us embark on a galactic journey, dodge asteroids, battle enemy ships, and conquer the vastness of space. 
This project serves as both a fun gaming experience and a great introduction to creating 2D games with Godot.

** About our game


** About Godot
Godot Engine is a powerful, open-source game engine designed for both 2D and 3D game development. 
It is highly versatile, lightweight, and accessible to both beginners and experienced developers


** How to Play
```
Arrow keys / W A S D for movement
Space for enter
Esc for exit
```
